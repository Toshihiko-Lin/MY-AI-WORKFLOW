## 总则

- MD 优先：在 `main.md` 里写、改、存档
- 不在 TeX / doc 里撰写或修改正文
- 格式转换仅限投稿格式化，转完不回改

## 文件结构

```
[专业文件夹]/论文/[序号]-[论文名]/
├── 00-索引.md          ← 唯一入口：当前状态 + 导航
├── 论文信息.md          ← 元数据 + 研究内容 + 写作方向
├── 修改记录/            ← 决策日志 + 活跃待办
│   └── YYYYMMDD_[事项].md
└── main.md             ← 论文正文（Git 管理）
```

## 写改流程

1. 对话里打磨，说"可以写进去了"再动文件
2. Edit 工具修改 `main.md` 目标段落；润色时附中文草稿
3. 定位：`grep -n` 找行号 → 按范围读取 → 写回
4. 引用格式：`[@citekey]`（Pandoc Markdown）
5. 已完成的修改 → 在修改记录里打勾补结论

## 修改记录规则

只写"为什么这么改"——决策理由、待办、结论。

- 当次改完 → 写决策摘要
- 改不完 → 用 checkbox 附决策理由，改完打勾
- 查待办：`grep -rn "\- \[ \]" 修改记录/`

## 告一段落

1. 修改记录按规则写入
2. 更新 `00-索引.md` 当前状态
3. 写作方向有变 → 更新 `论文信息.md`
4. 更新任务追踪
